The upstream attribution set is a conservative source-module envelope. Some
declarations concern optional/platform-specific code that the wheel may not
have compiled for Windows. NOTICE-INVENTORY.json, one directory above this
folder in the installed product, records the actual collected native files,
retained Qt DLL modules and omitted unused modules. It is not an SBOM claim
about every statically incorporated object inside the vendor DLLs.

The recipe omits unused GPL-only Qt module families (including Timeline,
Lottie, Virtual Keyboard, Quick3D, PDF and QML Compiler when collected) and
rejects unexpected Qt DLL modules for review. The optional Mesa software
OpenGL DLL is also omitted; the client uses Qt's normal Windows D3D rendering
path. No source/license assertion about a bundled Mesa binary is made because
that optional binary is not distributed by this recipe.

Exact installed LICENSE/NOTICE/COPYRIGHT files for Python, NumPy, OpenCV,
Pillow and psutil are copied into the adjacent dependency-notice collection;
their original third-party terms continue to apply. Native runtime/system
components in the final artifact still require review against their own
