# 教程配图来源

18 张界面配图已在 Windows、PySide6 6.11.1、`QT_SCALE_FACTOR=1.5` 下，使用当前真实 QtClient 重新截图；基于已合入 #73 的 main `ace6cdee650c02b4e054373507a7444fb3076b41` 与本 PR 的教程整合界面。中文字体来自 Windows 的微软雅黑。截图未开启全局输入或游戏采集。

图中的作者、地图、路线和运行中状态是隔离沙盒的合成演示数据，不是真实玩家数据或识别成功证据。其余 13 张为明确标注的操作示意图，其中游戏控件、显隐按钮和悬浮球三图的真实控件部分也已按组合后的 UI 重截。教程以当前文字说明和实时快捷键为准；后续布局变更时应重新核对界面配图。

Qt 图片使用内置 PNG 解码。安装时模块在 `_internal/client_tutorial.py`，图片在其旁边的 `_internal/tutorial/` 子目录，章节文件在 `_internal/tutorial-chapters.json`。已有帮助页的操作图入口及图片映射保持原样。
