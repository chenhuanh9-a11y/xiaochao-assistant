# 作者资源免重启导入

本变更基于 PR21 的“实际使用路线”选择器。PR21 未合并前，本 PR 以其功能分支为 base；不包含 PR20 的贴合回归修复，也不改变已发布安装包。

## 使用

在结束本局、地图关闭且后台识别/资源加载完成后，打开“地图资源”，选择现有地图导入 ZIP。检查通过后点击“导入并刷新”。作者选项和资源预览自动刷新，然后在“实际使用路线”选择作者；原有作者/自定义图库偏好保持不变。无需退出软件。

展十困难、滋酥居噩梦、王清心噩梦、爱吃醋噩梦沿用现有 packageId 和 schema1。爱吃醋继续使用兼容 ID nightmare-nightingale；blocked_geometry 楼层继续回退结构底图。

仅允许追加对应作者图片与精确列出的 catalog/display-bindings sidecar。缺核心资源或替换旧资源仍使用原“退出并导入”升级流程，不进行对局内热换包。

## 生命周期

主控在 UI 线程取得空闲租约，暂停新开局、模式/路线切换和新导入选择。后台线程复用完整 ZIP 校验、OS 写锁、暂存、原子文件发布和回滚；不调用 Tk。取消不会提前释放租约，关闭请求先取消并等待完成，再由用户关闭。

完成事件必须属于当前请求、资源根、模式和 pack。UI 线程重建资源上下文、清理旧图片回调代际/缓存、刷新作者选择及资源页；不运行识别或贴合求解。receipt 是提交点，提交后才到达的取消按成功处理。文件已提交但刷新失败时明确提示重新检查/导入以重试刷新，不谎称磁盘已回滚。

## 验证范围

合成测试覆盖四包白名单、首次/重复、取消与失败回滚、核心/自定义数据保护、UI 线程接收、迟到事件拒绝、导入期间开局阻止、旧预览缓存失效。实际四份 Q90 导入包在私有独立安装目录中走生产检查/后台导入/完成消费者与资源 factory；首次新增90/72/74/74文件，重复各0。三噩梦作者和困难代表图通过真实 PIL 解码，307基础资源（含132预制）及自定义标记、原路线偏好不变，0 rank/solver 调用。

没有 GUI 点击、真实游戏、安装或线上发布验收。私有原图/日志/资源不提交仓库。软件试用只交付 Setup，不生成免安装软件 ZIP。
