## 实际入口和边界

`ClientOnlinePackages.qml` → `OnlinePackagesService.checkPackages/downloadPackage` → 后台 `_Work` → `MapPackageDownloadService.read_index/download_package` → `_complete` → `ImportedResourceService.importVerifiedArchive` → `_import` 的 `inspect_archive/save_archive` → 导入准入、自动启用与最终库存。

生产 `client.py` 显式配置 `save_only=True` 且已安装查询返回 `unverified`，因此当前生产入口不会扫描旧安装文件；默认 `OnlinePackagesService` 的收据扫描供旧包管理入口使用，不能将默认构造器的扫描耗时冒充当前生产耗时。下载源只来自 `STAR_MAP_PACKAGE_INDEX_URL`，没有内置地址；本轮进程未配置该值。

### 受控来源：同机三轮交替

**没有测出稳定的下载提速，不报告提速倍数。** 删除了一遍成功路径的摘要运算，最终实际文件读取仍必需，没有省掉整包落盘复读。首次下载中位数反而略高；缓存代码未改但样本也有较大波动，不能据这三轮认定缓存变慢或实际网络提速。

### 缺口与续办

本轮没有配置可用的真实在线索引地址，派单也未附真实源链接，故互联网来源的三轮下载/缓存、真实网络传输仍**未测**。不把本机受控结果冒充完成标准中的真实来源实测。需要补给可读的在线索引（含两类配套包）及现行产品决定/已决定卡片的可读副本；按发卡规矩进入每日待提供清单，不发卡、不设连接重试。收到后只做真实来源剩余计时及决定对照，不重做已完成的实现、受控测量或导入。

未验收：真实页面点击到可见结果、真实互联网、其他电脑、安装/游戏和作者配准。本分支不合并、不构建或发布安装包。

## 整合

`agent/load-speed-1-strip-checks` 负责导入/激活/读取，可能涉及本文件列出的交接边界和缓存；本分支不摘取、不重做它的改动。`agent/render-map-1-dual-pack` 负责结构包渲染图与独立路线包，包角色和依赖应由导入边界检查。最终记录实际重叠文件，统一整合到同一提交后再核对下载绑定、坏缓存、取消、包角色与依赖；任何下载测量都不代表已安装或游戏验收。

本轮核实对方远端分别为 `703ebf8` 与 `e279a54`：与本分支的产品、测试、文档和工具文件**没有实际同文件改动**。加载任务实际在 `imported_resource_archive.py`、`client_imported_resources.py` 等处理后续绑定和保存；渲染图任务在 provider、包导出及独立路线验证处理消费者。整合点是下载输出的 packageId/bytes/sha256、角色后缀、导入请求代次，以及加载任务的新保存绑定；不能因暂未发生文本冲突就省去联合交接测试。未改对方工作区、工作流、安装发布脚本、默认安装或未点名模块。
