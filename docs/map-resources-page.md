# 地图资源页面

本页采用已确认的作者卡片、大图预览和详情布局。浏览噩梦或困难、查看作者与楼层均不改变当前游戏模式、地图身份或实际路线。只有“使用…”按钮调用原作者选择控制器；导入、下载或更新不会自动选用作者。

## 操作与状态

- “已安装”来自本机资源声明与安装记录，在线服务未配置或失败时仍可浏览、导入和管理。
- “发现”沿用下载索引。现行索引没有远端预览图或地图覆盖字段，因此未安装图包显示占位，更新后的覆盖标为待检查，不编造缩略图或覆盖率。
- 地图数按当前浏览模式统计，缺失楼层另计。实际可选作者仍以控制器能力为准，另一浏览模式不会隐式切换游戏模式。
- 导入、重复导入、下载重试、修复和备份移除继续使用原检查、哈希、安装与取消流程。移除必须经过独立确认，并保留 receipt/plan 校验。
- 移除确认还绑定浏览模式、选中图包和资源代次；切图包、切页、离开或刷新资源后失效。取消按钮按真实任务路由，本地导入及管理的共享任务不会误取消在线令牌。
- 窄窗口使用列表/详情切换，详情可滚动，返回入口和当前实际作者摘要保留。

## 线程与缓存

`map_resource_context` 只读取资源声明、作者目录及文件时间/大小，不构造识别引擎或读取结构像素。单个元数据 worker 仅保留正在处理和最新待处理请求，结果按浏览代次接收；两种模式上下文最多缓存两份。可选作者声明损坏单独报告，不隐藏其他正常作者。

页面复用 `MapResourceBrowser` 的两个图片解码 worker、最新请求替换、最多 64 个待处理请求及 48 项/32 MiB 像素缓存。Tk 图片只在 UI 线程创建，旧代次、已销毁或已改请求的控件不接收旧图。切标签复用作者卡片，关闭时释放页面图片引用。

新页面周期渲染不重新查询作者选项。作者快照经既有显式同步链更新；导入组件可用性在检查 worker 中记录，快照读取不再逐轮 stat 组件。既有桌面作者同步链的资源存在检查仍保留，本改动不宣称整个桌面所有 UI 文件访问均已消除。

## 验证边界

定向用例在 `test_map_resources_page.py`、`test_map_resource_context.py`，结合原 preview、管理、安装状态、下载缓存恢复与作者选择控制器回归。测试覆盖真实 Tk 页面入口、缩放、重复操作、上下文失效和安全操作接口；网络、确认窗口和部分控制器使用隔离夹具，不代表玩家实际下载、游戏或安装验收。

页面截图和压力记录保留在工作区审计材料，不将实际作者图片提交到仓库。回调间隔只表示隔离事件循环观测，不是屏幕 FPS、游戏端到端延迟或长期内存泄漏证明。没有在本轮制作 Setup 或修改已发布版本。
