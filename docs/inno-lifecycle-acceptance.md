# Inno 安装生命周期验收工具

本工具属于「安装与更新」，只新增验收执行器、报告判定及用法文档；相邻影响为「地图资源」和「自定义图库」数据快照的回读检查。它不实现安装、迁移或卸载，也不把迁移准备副本当成安装成功。

## 安全边界

默认只做计划预检：

```powershell
py -3.13 tools/inno_lifecycle_acceptance.py lifecycle-spec.json --report work/acceptance/plan.json
```

只有在**已提供可丢弃隔离 Windows 环境**、真实安装包和历史包，并核对正式产品身份后才能加 `--execute`。spec 必须显式列出 `disposableWindows: true`、`productIdentityVerified: true`、`allowedRoots` 和每个场景的隔离 `root`。不得在日常电脑、服务器或正式用户目录运行；工具不提权、不改权限、不强杀超时进程。执行命令均为参数数组（无 shell），运行超时后标失败并停止该场景的后续步骤。

每个包声明 `path`、`version`、`sourceCommit` 和 `sha256`。QtIFW、旧 Inno 与目标 Setup 都要求真实输入；合成包只能用于单元测试，不能满足包来源或真实 Windows 验收。场景命令和检查项写在 JSON spec 中，避免工具猜测某一台机器的登记和产品路径。检查项可记录文件/登记观测；观察结果区分 `present`、`absent`、`access-denied`、`not-checked`。被拒绝或没检查不算清理干净。

## 生命周期矩阵

spec 中可以按实际已有适配器声明这些独立场景：新装、真实 QtIFW 到 Inno、旧 Inno 到新 Inno、重装、主动全清、取消、中断后重试、文件被占用、普通用户/取消提权、上次安装不完整、助手挂起和崩溃。每一步记录命令、退出码、耗时和独立观察快照。测试样本需预置设置、自建路线、自定义图库、成套资源及安装根之外的无关哨兵，并逐项验证内容与资源收据/快照/依赖；升级应验证新版本准入，不能直接激活迁来的旧收据。

全清观察应覆盖程序目录、按正式归属核实的 LocalAppData/AppData/ProgramData 根、设置缓存、资源、自建内容、迁移暂存/备份、两种视图的用户及机器登记、快捷方式、启动项、卸载入口及旧 QtIFW 维护入口。禁止按名称扩大删除范围。执行环境和产品接线需提供明确的无 shell 命令适配器及逐项断言；运行中的进程、超时退出码、未完整安装等场景应保留在报告中。对无法观察的项应记录为未检查，不推断为零残留。

状态 `passed` 只代表场景中列出的实际步骤与断言在隔离 Windows 环境满足；CLI 输出成功或安装器退出码为零本身不足以通过。`prepared-native-unverified`、`nativeInstalled: false`、缺少历史包、无权读取或没有观察到的结果都不能通过升级/全清验收。当前 PR #147 在原生切换前停止，所以此工具在该提交上不会报告真实升级已通过。

## 报告与限制

逐场景 JSON 报告包含包来源信息、命令、耗时、退出码、观察结果、错误、残留和 `passed`/`failed`/`blocked`/`skipped` 状态。当前服务器环境没有隔离 Windows 实例、真实历史 QtIFW/Inno 安装包或正式登记库存；本地测试仅验证输入门禁和报告判定，不是原生 Windows 安装验收。待 PR #147、第1项卸载页面工作和 1889 迁移接线有统一可测提交后，在可丢弃 Windows 环境提供实际适配器，按上述矩阵运行并审查完整报告；此后由 huan 在本人电脑验收正式发布。
