# Inno 安装生命周期验收工具

本工具属于「安装与更新」，相邻影响是「地图资源」和「自定义图库」的升级数据观察。它只做计划预检，不实现安装、迁移或卸载，也不把准备好的旧版副本算成真实安装通过。

## 当前执行边界

```powershell
py -3.13 tools/inno_lifecycle_acceptance.py lifecycle-spec.json --report work/acceptance/plan.json
```

当前版本**禁用真实生命周期执行**。没有由可信调用方在工具外独立核实的可丢弃 Windows 环境及测试产品上下文，因此即使加 `--execute`，工具也会在启动任何进程前返回 `blocked`。spec 中填写 `disposableWindows: true`、`productIdentityVerified: true`、路径或哈希，都不能解锁执行。产品安装程序能越过当前目录写入系统，命令白名单和目录白名单也不能替代隔离环境。哈希只核对文件是否一致，不能证明安装包安全或进程受隔离。

spec 是不可信数据，不接受命令、解释器、脚本或参数入口，也没有当前可用的动作适配器。所有包路径和观察路径必须是允许根目录内的绝对路径；观察目标还必须在对应场景根目录里。相对逃逸、UNC/设备路径和符号链接路径会被拒绝。报告输出也必须落在明确的允许根目录内。登记观察目前完全禁用，直到可信调用方能独立核实测试产品身份并据此固定精确登记项。

每个包声明 `path`、`version`、`sourceCommit` 和 `sha256`。真实 QtIFW、旧 Inno 与目标 Setup 仍是将来 Windows 验收所需的输入；合成包只能用于测试拒绝逻辑。预检成功只表示输入结构和当前策略检查通过，不代表已执行场景。

## 生命周期矩阵

将来的可信 Windows 运行器需覆盖新装、真实 QtIFW 到 Inno、旧 Inno 到新 Inno、重装、主动全清、取消、中断后重试、文件被占用、普通用户/取消提权、上次安装不完整、助手挂起和崩溃。每个场景需观察实际退出码、耗时、文件与登记状态；升级需检查设置、自建内容、地图资源及其凭据的迁移结果。全清还需核对程序目录、正式归属的数据目录、缓存、迁移暂存、快捷方式、启动项和旧维护入口，并保留安装目录外无关哨兵。

可信执行方案必须在产生任何业务动作前完成所有场景、步骤、输入输出、报告位置及观察项的整体预检；任何越界项都要让整轮零启动。错误退出、超时、访问拒绝、缺观察、准备副本、无权读取和未检查都不能算成功；登记查询错误也不能推断成「不存在」。

## 报告与限制

报告的 `blocked` 表示未启动任何生命周期进程；`preflight-only` 仅表示场景已列入计划，绝非场景验收通过。当前服务器环境没有经独立核实的隔离 Windows 实例、真实历史安装包或正式登记清单，本地合成测试不能替代 Windows 生命周期验收。PR #147 的准备态也不代表升级通过。待可信运行器和所需接线具备后，仍须在可丢弃 Windows 环境完成实际检查；正式发布由 huan 本机验收。
