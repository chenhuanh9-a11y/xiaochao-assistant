# 功能测试包：使用与反馈清单

此页属于独立功能私测包。实际可安装版本以交付时的 Setup 文件名、源码 SHA 和 SHA256 为准，文档存在不表示安装包已完成验证。

## 先确认装对包

- 本包名为 **Xingtu Feature Test**，与“Xingtu S1 Playtest”识别贴合包、正式版分别安装和保存数据。请不要选择正式版或其他私测包的目录。
- 只保留 S0、S1 的困难和噩梦模式；S1 普通模式已退役，不需要补回普通图包。
- S1 使用私测资源和当前识别候选链，尚不是正式实机准确率验收。资源缺少绑定或侧门信息时应明确提示，不应凭空显示正确状态。
- 不需要迁移、清理或覆盖正式版数据。资源导入试验请只在本包内进行。

## 建议按顺序测试

### 1. 开图键与开始本局分开

1. 绑定游戏后，先不点“开始本局”，按游戏开图键。游戏可以照常开关地图，助手不应开始识别，也不应开启新一局。
2. 点击“开始本局”，再按开图键。助手应进入识别和贴合；开关地图不应重复创建新一局。
3. 点击结束本局，再按开图键。助手应等待下一次明确开始，不能自行恢复上一局。
4. 开图键与开始键不能配置成同一个按键。快速连按、准备中开关图也不应让下一次开图相位错乱。

### 2. 识别、锁图和贴合

- 分别试 S0、S1 的困难和噩梦。先确认实际楼层，再看助手楼层与地图是否一致。
- S1 确认锁图后，反复开关图、换楼层和移动地图。应该只处理本局已锁定地图，不重新扫描其他地图。
- 当前画面不足以贴合时，可以保持已锁地图信息或静态参考，但不能把上一帧的贴合位置当成当前结果。结束本局后才能重新识别下一局。
- 留意贴合偏移、错层、错误换图及长时间等待。请记录模式、楼层、操作顺序，以及问题出现前是否已经锁图。

### 3. 连点开箱偏好跨局保留

- 开启一次后，结束本局应立即停点击，但开关偏好不应被清空。
- 下一次明确开始并进入有效对局后，才可按原偏好恢复；没有开始、游戏不在前台或手动关闭时不应点击。
- 快速开始后取消，再开始下一局，不能被旧任务意外重新开启。

### 4. 公告与资源页

- 有未展示的新公告时，启动后应显示公告弹窗。关闭已看公告后，普通切页、隐藏再显示不应反复弹同一内容。
- 同版本公告内容更新可作为新公告出现。没有新公告时没有弹窗是正常的。
- 资源页不应再把完全未安装的 S1 普通图列为缺包；当前困难、噩梦的真正缺包或坏包仍应提示。
- 可在本测试包导入自己常用的作者图包，切换作者和楼层，检查显示是否刷新正确。失败应说明原因，不能把旧层图冒充新图。不要用正式版的数据目录做试验。

### 5. 启动、进度与日常操作

- 冷启动、资源加载应有可理解的状态或进度，结束后不能一直转圈。
- 反复切页、开关图和开始/结束几局，观察页面是否闪烁、卡住，或内存持续上涨。
- 这些测试用于发现问题，不表示已达到 500ms 首贴、300ms 后续开图的目标。

## 本包不要求你测试

正式版覆盖升级、旧资源清理、卸载向导、游戏启动联动，以及尚未纳入本包的新缓存预算和资源历史回退。不用为了测试本包卸载正式版或清理旧图包。

## 怎样反馈最有用

请给出 Setup 文件名、赛季/模式、楼层、是否已锁图、从哪一步开始异常，以及可复现的按键顺序。截图尽量只含相关游戏区域；有错误提示时保留原文。若问题偶发，说明尝试次数和出现次数即可。
