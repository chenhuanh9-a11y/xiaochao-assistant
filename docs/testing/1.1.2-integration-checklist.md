# 1.1.2 覆盖升级候选：范围与验收清单

本轮按用户要求使用正式安装身份与版本 1.1.2（数值版本 1.0.0.24），用于受控验证；不是已发布版本。本文不是安装授权，也不表示 Setup 已生成。不得用 `/DIR` 把同 AppId 的安装误称为完全隔离安装；它仍可能改写现有登记。

## 当前源码已整合

- 已交功能包的 S0 楼层召回、S1 本局锁图、贴合与显示、开图键和开始本局分离、开箱偏好跨局保留、启动进度、卸载选择和游戏启动联动代码继续保留。
- 局外开图键保持游戏透传，不启动本局，也不再弹冗余提示；显隐控件静默。
- 图包单删和批量清理使用明确确认后的删除事务，涵盖可证明归属且未改动的当前/历史作者快照。未知或改动文件保留并明确报告，官方底模、自建路线与设置不是单删作者包的目标。导入仍完整解码验证，读取已安装作者包延迟到显示消费者解码。
- 两个结构缓存使用各自 512 MiB 软预算；不是进程总内存上限。贴合只复用一次观察内完全相同的规范残差数值，不跨帧复用，不放宽图/层/位姿验收。
- 主页公告入口及正常启动主动读取，已读去重、同版本正文更新可提醒；探针不联网。移除重复教程、识别详情和回放页面，保留完整教程、手动操作、实际诊断导出与离线算法验证。
- 1.1.2 与导入 helper 共享严格版本合同，不接受未来未知版本冒充受支持版本。

## 构建前尚须完成的硬门槛

1. 无硬链接文件系统：兼容实际 `resource-hardlinks-unavailable / WinError 1`，不能只清空旧目录或取消预检。基础资源、覆盖重置、安装器证明、作者导入/删除和异常恢复必须使用可验证且原子不覆盖的合同；当前实现仍在独立开发，不能称已纳入。
2. 最终同一源码提交的 Windows CI、正式资源逐文件哈希及来源锁、版本/source fingerprint 重算。保留严格生产锁，不能沿用私测包许可绕过。
3. 在受控 Windows 环境验证 1.1.1 → 1.1.2 正式身份覆盖、确认/取消、准备/发布/原生登记期间中断及恢复。不得覆盖用户现用正式安装，也不得据临时模拟宣称原生完整通过。
4. 正式安装器旧图包清理范围：按盘点及确认隔离已识别旧资源/图包，保留设置、自建路线、编辑内容和非目标文件；对混合/改动对象明确处理结果。旧文件的无恢复删除不是默认动作。
5. Setup 新装/升级后的启动、资源验证、必要 UI 操作及卸载向导。实际游戏识别、长期 RSS 与输入到正确显示的延迟仍须用户实测，不由算法局部计时替代。
6. 作者历史回退新界面尚未纳入本树，不能在本候选公告中声称完成。本文列出的现有快照删除不代表历史回退功能已开放。

## 交包后的简明测试顺序

最终交付前由负责人补确切 Setup 路径、SHA256、源码与资源哈希，并标明哪些升级测试已由受控环境完成。

1. **升级与启动**：核显示 1.1.2，旧图包处理提示能说明范围；取消不得偷偷清理。完成后设置/自建路线保留，无旧图包错误和硬链接错误。不要自行删除整个数据目录。
2. **开图和锁图**：局外按开图键只影响游戏；明确开始后再识别。锁定后换层、关图重开、移动地图仍是同一图；证据不足时暂停贴合，不拿旧帧冒充。换图需要结束本局再开始。
3. **贴合与作者图**：S0/S1 困难和噩梦分别试楼层和作者切换，记录错图、错层、偏移、空白或长等待。作者选择不能改变已锁地图或结构位置。
4. **图包管理**：导入后首开与再开图库；删除时先取消，再确认；清理全部时查看保留项。删除后旧入口不应残留，重启后也不应自行恢复已删作者图。
5. **开箱和常用操作**：开箱偏好跨局保留，但结束、失焦、取消或主动关闭后必须停止输入。控件显隐安静，关闭窗口三种操作结果清楚。
6. **公告与页面**：启动新公告主动显示，主页可重看；切页或恢复窗口不重复弹已看公告。只剩一套教程，低频维护在“更多”，错误、恢复、确认和取消仍可操作。
7. **稳定性**：多次切页/换作者/开始结束后观察卡顿、内存持续增长、进度转圈。反馈包名、赛季模式、楼层、锁图状态、操作顺序与错误原文。
