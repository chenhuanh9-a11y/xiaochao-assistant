# 定点地图位置编辑

右上角的静态参考图在界面中称为“定点地图”。设置页和悬浮面板使用同一组主控接口：点击“编辑位置”，拖动预览，点击“完成”保存位置并退出编辑。松开鼠标只结束一次拖动，不会结束编辑。

编辑使用独立的原生预览窗口。设置页在前台时也能编辑；正常定点地图和贴合路线的前台、地图与显示授权条件不因此改变。预览不确认地图、楼层或贴合变换。关闭显影、结束本局、上下文失效或窗口销毁会取消编辑，迟到的指针事件不能恢复旧预览。

位置沿用 `sheetPosition` 设置。编辑开始和拖动时按当前显示器工作区约束位置；原显示器移除或工作区变化后，再次编辑应把位置带回可见区域。首次编辑沿用正常地图的默认位置，不因为设置页位于另一块屏幕而跳屏。

## 原生回调边界

历史拖动故障的转储证明了 Tk/Tcl 原生边界发生致命退出，但没有直接证明 motion 回调就是故障栈。后续版本曾禁用位置编辑；本次实现不以删除禁用条件代替重做生命周期。

`reference_position_editor.py` 保存 UI 线程拥有的编辑状态，以及只包含标量样本的指针邮箱。`LayeredOverlay` 的既有原生窗口过程负责捕获和投递，主控事件轮询消费样本并更新位置。原生指针路径不调用 Tk、`after` 或界面日志；不再由主控给参考图原生窗口安装额外的 Python 窗口过程子类。编辑代际、窗口句柄和上下文共同限制迟到事件的消费范围。

## 验证范围

UI 测试运行实际视图方法，以明确的控件和主控 I/O 替身验证入口、完成及失败反馈。主控和原生消息测试分别验证位置状态与原生边界；它们不能代替用户的实际鼠标拖动、多屏体验或原崩溃复现。

本功能通过独立草稿 PR 交付。未操作现用游戏窗口，未安装或替换用户程序；是否完成实机验收单独记录。
