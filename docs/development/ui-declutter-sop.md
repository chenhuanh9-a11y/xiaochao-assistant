# 界面断舍离 SOP

本轮目标：玩家能直接开始、看图、换路线和处理问题；界面不持续解释内部识别流程。按用户本轮截图与明确指令实施，不借清理修改识别算法或删除用户数据。

## 处理规则

1. 先查用途和调用：页面入口 → 操作 → 状态写者 → 任务/缓存 → 最终消费者。区分独占实现与共用能力。
2. 重复入口只留明确的一处。低频维护放在就近的“更多”或可展开设置，不藏进无关页面。
3. 常驻文字只留操作名称、真实进度、结果和需要用户处理的问题。详细原始错误保留在诊断中；风险、删除范围和失败原因不静默吞掉。
4. 用户明确淘汰且未查到实际排查价值的“识别回放”“识别详情”，删除页面、路由、专属加载和显示实现。算法离线样本测试、共用采集、日志、诊断导出、实际手动选图/楼层操作保留。
5. 简化用词后核对实际效果，不能只换文案而保留重复控件。按钮鼠标、键盘、取消、重开、错误和迟到任务分别验证。
6. 分批提交后统一集成；最终 Setup 从固定远端提交构建。云端离屏 UI 验证与 Windows/游戏实测分开记录。

## 本轮分批清单

| 区域 | 处理 | 必须保留的行为 |
| --- | --- | --- |
| 图包管理 | 下载/导入直达；完整性检查、恢复记录、批量清理放入“更多”；成功列表不常驻解释流程 | 单包真实删除入口、取消与确认范围、错误、恢复中的状态、导入进度 |
| 设置和开箱 | 去除候选锁定等内部说明及重复状态；长操作说明按需展开 | 持久设置、跨局开启意图、暂停/错误原因和安全释放 |
| 窗口关闭 | 删除重复最小化按钮；关闭选项为“后台运行 / 退出星图 / 取消” | 原生最小化、后台驻留、真正退出排空、取消不改状态 |
| 教程 | 删除帮助页四个旧折叠卡及其 JSON/API/打包项 | 上方完整教程、当前快捷键、章节进度、操作图 |
| 反馈 | 采集/导出选项集中到“反馈设置”；隐私说明精简但常驻 | 默认诊断导出、只导文字、局部/完整画面选择、停止采集、原始错误 |
| 识别详情/回放 | 按依赖清理用户侧页面与独占实现 | 首页明确手动选图和游戏控件；共用采集与离线验证 |
| 公告 | 主页可直接查看；正常启动自动获取未读公告 | 已读不重复、同版本修订提醒、加载/失败重试、关闭及后台不抢焦点 |

主页、资源、设置、帮助和关闭窗口列入检查。自定义路线编辑、路线广场、浮窗、游戏控件等真实功能不因“低频”擅自移除。隐藏候选控件时仍须有可用手动选图入口。
