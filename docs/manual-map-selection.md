# 手动选图

主页 → 设置 → 游戏与路线 · 更多设置 →“选图方式”，或游戏控件“模式与选图”组切换“自动识别 / 手动选图”。设置保存为 `ui-settings.json` 的 `mapSelectionMode`（`auto` / `manual`），缺省或未知值按自动识别。

手动选图沿用旧版 PC 快速选图的操作：`Alt+1`（快捷键“手动选图”，可改键）或游戏控件的“选择本局地图”、更多菜单的“选择地图”打开选图窗。先选路线组合（噩梦按图名前缀“左中右 / 左中 / 左右 / 右中”，无前缀的归“其他”；困难无前缀时按方向），再选地图；每页 4 张，`F1`–`F4` 或点击选择，`PgUp`/`PgDn` 翻页，`Backspace` 返回，`Esc` 关闭。只有一组时直接进入地图页。缩略图取入口层底图，后台解码并按地图包身份缓存。窗口不抢游戏焦点，选图键只在窗口显示时轮询，期间同主键的无修饰功能键不触发。

## 接缝

- 只在“手动选图且本局未锁图”时跳过身份识别：`_capture_and_rank` 不调用 `engine.rank`，也不带入正门种子、来源结构候选或旧诊断；`_rerank_current` 直接返回。截图、开关图、楼层读取照常，`ranked` 事件以空候选到达，不会自动锁图。
- 选中地图走 `confirm_route`，与人工确认候选同一提交：写 `activeConfirmation`、清旧组、开图时显示定点并开始贴合。楼层未定时以手动楼层或入口层为种子，锁图后的帧照常读取真实楼层。
- 已锁图后两种方式行为相同；“结束本局”后手动模式等待下一次选图。切换难度时重新列出地图，旧地图包的选择和缩略图结果被丢弃。
- 旧设置的 9 项功能键迁移时，只有 `Alt+1` 未被占用（含地图键与开箱连点按键）才作为默认值，否则留空。

回归位于 `tests/test_manual_map_selection.py`（分组、翻页/按键、迁移、提交接缝）。Mac 上快捷键迁移用例需替身才能导入主模块，未替身时跳过。Tk 检查只用隔离窗口；真实游戏内选图、贴合与 Windows 打包尚未验证。
