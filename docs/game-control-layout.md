# 游戏控件布局

主页 → 设置 → 游戏控件 → 自定义，或游戏控件的“更多”菜单进入。

默认保留状态/当前楼层、贴合与定点显隐、本局动作三组。可勾选并调整显示、模式与选图、候选与再识别、本局动作的顺序。显示组下可单独启用两项不透明度与定点位置编辑。只有“精简”和“常用”两个预设。

状态摘要、收起和更多入口始终保留；没有手动楼层。可选内容超出工作区时滚动，状态区与位置编辑的完成/取消固定可见。位置编辑期间不能收起为圆球。显隐按钮表达用户开关，是否实际显示由状态摘要说明。

快捷键提示来自当前 `hotkey_editor_snapshot`，重新绑定后同步更新；未绑定不占位。呼出/隐藏控件的绑定可在更多菜单和布局设置中查看，布局设置不新注册快捷键。

`gameControlLayout` 是独立的版本化偏好。草稿、取消、恢复默认不调用游戏命令；应用仅保存布局，不修改模式、地图、楼层、透明度、显隐或本局状态。保存失败保留原布局。旧设置缺键、未知模块或坏格式回到精简布局。预览复用实际 `GameControlView`，所有运行命令禁用。

回归位于 `test_control_layout.py`、`test_control_layout_editor.py`、`test_control_layout_view.py`；位置/透明度沿用各自控制器回归。Tk 检查仅使用隔离测试窗口，不能视为已发布 EXE、真实游戏或长期运行验收。正式 1.0.4 和已发布安装包本轮不变。
