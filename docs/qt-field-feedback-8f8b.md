# Qt 8F8B 现场反馈修复边界

本次基线为 `8f8b14bda334ccf7bba26d1eadd87f723e83a34a`。六份诊断导出按 Qt session 和内容去重；历史非 Qt 日志不用于证明 Qt 行为。原始日志、截图、用户配置与构建产物均不提交。没有操作游戏、输入按键、覆盖安装或制作安装器。

## 状态与职责

- 显示授权仍由 LiveRuntime、AlignmentCoreV2 和 ClientCaptureProvider 校验。Session 的旧快照失效时，Coordinator 只允许保留已经显示、且经运行时再次验证仍有效的当前材料；失焦、关闭、新无效帧、资源或绑定变化仍撤显。没有延长连续显示或开图准备期限。
- 输入请求意图与原生监听安装成功分开。线程接受启动请求不再代表可用；失败后只恢复已有请求。临时无法核验窗口时停止游戏输入和捕获，保留本局；只有独立核验 HWND、PID、进程创建时间及程序身份失效才解绑并结束本局。
- 临时恢复后先重新观察当前地图，再按当前捕获上下文、epoch、cycle 和输入序列同步输入意图。普通状态快照不能授权恢复；迟到回执不能覆盖新的 Esc。暂停前排队事件和旧监听启动通知不能触发恢复后的游戏操作。
- 地图 X 使用当前完整客户区帧的 X 形状证据和实际客户区坐标；宽泛右上区域不再直接授权关闭。无证据时仍可由后续地图观察确认关闭。导航按钮不应改变开关意图。
- 连点保留键取自实际编译结果。配置冲突解除只清配置错误，真实发送/释放错误及未释放按键记录不清；冲突后仍需用户显式重新启用。
- 失败采样默认关闭。帮助页启用后，仅保存已有失败捕获帧及测量信息，复用现有采样限额；不额外截图，不改识别/贴合阈值。关闭采样停止新增，已有样本仍受原有保存规则管理。诊断轮次的额外磁盘写入不纳入性能验收。
- 安装包报告由当前冻结结果生成并作为程序文件更新。仅重做安装器时，运行模块提交与安装器包装提交分开记录。导出线程独立计算实际 EXE、固定模块源码副本及资源声明的有界哈希；声明哈希不是全资源审计，保留的用户资源可以有不同版本。

## 现场证据限制

已观察到旧 Session 完成回调清掉较新拖图材料的序列。指定的八次迅速撤显则全部先出现 `map-closed` 清空，随后才报 `payload-expired`；旧日志没有记录该关闭输入的来源，不能把八次都归入同一竞态，也不能将失败称为正常行为。新增关闭来源和代际诊断供后续定位。

几何拒绝和准备期限失败仍缺对应失败帧及当时楼层高亮、裁剪、地图组/代表成员证据；没有据失败标签调整算法。附带的 `invalid-archive-count` 也缺当时选取的原始导入文件，未推断为用户误操作。

## 验证口径

定向测试分别从精确 8F8B checkout 与修复 checkout 导入生产模块，先复现失败再验证修复。真实执行设置持久化、键编译、捕获提供者的上下文校验、运行时、授权核心、Session/Qt 回调、Coordinator 和现有样本存储/导出；原生窗口、按键、截图像素、部分求解输入及显示窗口使用隔离替身。保存的用户截图只用于离线命中核对，未加入测试资产。
